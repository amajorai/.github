# A Major

Simple, minimal Claude Code skills for shipping apps.

## Flagship Skills

| | Skill | What it does |
|-|-------|-------------|
| 📦 | **[ship.md](https://github.com/amajorai/ship.md)** | End-to-end feature shipping. Up to 10 quality-gated phases: interview, explore, plan, implement, verify, edge cases, E2E, simplify, security review, final verify. |
| 🪅 | **[vibe.md](https://github.com/amajorai/vibe.md)** | Spin up a production-ready full-stack environment. VPS provisioned, Bun installed, GitHub CLI wired, Dokploy/Coolify deployed, project scaffolded. |
| 🎉 | **[party.md](https://github.com/amajorai/party.md)** | Use GitHub issues and projects as a kanban board to ship features 24/7 autonomously. |
